# Jarvas

A small Python/Tkinter student portal sign-in screen demo.

## Requirements

- Python 3
- - Tkinter (included with most standard Windows Python installations)
 
  - ## Run
 
  - From the project directory, run:
 
  - ```powershell
    py now2.py
    ```

    The app opens a student sign-in screen with email/ID and password fields,
    a show-password option, and basic empty-field validation.

    ## Demo limitations

    This is a user-interface demo only. It does not authenticate accounts, connect
    to a school system, or save or send the entered information. Do not enter a
    real password.
